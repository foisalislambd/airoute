# Support

AIRoute is a community open-source project. Maintainers help when they can;
there is no paid SLA yet.

## Where to ask

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/foisalislambd/airoute/issues/new?template=bug_report.yml) |
| Feature idea | [GitHub Issues](https://github.com/foisalislambd/airoute/issues/new?template=feature_request.yml) |
| Usage / how-to | [Docs](docs/README.md) · [Issues](https://github.com/foisalislambd/airoute/issues) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private advisory only |

## Before opening an issue

1. Confirm you are on a recent `main` commit.
2. Run `npm run dev` (or your usual start path) and reproduce once.
3. Check [docs/guides/TROUBLESHOOTING.md](docs/guides/TROUBLESHOOTING.md) if present.
4. Search existing issues for the same error message or stack.

## What to include

- AIRoute commit SHA or version
- Node.js version (`node -v`)
- OS
- Exact steps to reproduce
- Relevant logs (redact API keys and tokens)

## Out of scope for free support

- Private debugging of third-party provider account bans
- Custom production architecture reviews
- Guaranteed response times

For commercial or priority support, contact the maintainer via the
[repository](https://github.com/foisalislambd/airoute) profile.
