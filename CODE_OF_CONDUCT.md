# Code of conduct

WowRouter is a small open source project. People who use it, report bugs, or send changes are expected to treat each other decently.

## Expected

- Assume good intent.
- Comment on the code and the behavior, not the person.
- Keep secrets out of issues, pull requests, and logs. That includes provider keys and router keys.
- Accept a no when a change does not fit the project. The router stays local-first.

## Not acceptable

- Insults, harassment, or piling on.
- Publishing someone else's private keys, data, or messages.
- Spam, or pull requests that exist only to advertise.

## What happens

The maintainer may edit or hide comments, close reports, or block someone who keeps breaking these rules. If a conversation is going badly, write to the maintainer through the GitHub repository instead of escalating in public.

This is a practical standard for this repo, not a legal agreement.
