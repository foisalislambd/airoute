# @airoute/web

Next.js dashboard and HTTP API for **AIRoute**.

Run from the monorepo root:

```bash
npm install
npm run dev
```

App: **http://localhost:20128**

This package depends on `@airoute/core` and the open-sse engine via workspace aliases. See the root [README.md](../../README.md) for product overview and [STRUCTURE.md](../../STRUCTURE.md) for layout.
